# Fall Guys Clone

A third-person platformer game inspired by Fall Guys, featuring physics-based movement, obstacle courses, and AI-controlled competitors.

## Description / Descrição

**English:**
This project is a practical assignment created for the Game Production - Physics course at PUC Minas Digital Games program. It recreates the core mechanics of Fall Guys, including physics-based character movement, obstacle courses, and competitive multiplayer-style gameplay with AI opponents.

**Português:**
Este projeto é um trabalho prático criado para a matéria de Produção de Jogos - Física do curso de Jogos Digitais da PUC Minas. Ele recria as mecânicas principais do Fall Guys, incluindo movimento de personagem baseado em física, pistas de obstáculos e jogabilidade competitiva estilo multiplayer com oponentes de IA.

## Features / Recursos

**English:**
- Third-person camera perspective
- Physics-based character movement
- Obstacle course mechanics
- AI-controlled competitors
- Platforming challenges
- Dynamic gameplay scenarios

**Português:**
- Perspectiva de câmera em terceira pessoa
- Movimento de personagem baseado em física
- Mecânicas de pista de obstáculos
- Competidores controlados por IA
- Desafios de plataforma
- Cenários de jogabilidade dinâmica

## Technology Stack / Stack Tecnológico

- **Engine:** Unity
- **Language:** C#
- **Physics:** Unity Physics System
- **AI:** Unity NavMesh / Custom AI
